# 启动前检查清单（Pre-flight Checklist）

> 规则: 每次开机/恢复工作前必须逐项检查，不得跳过。任何 ❌ 项必须先解决再继续。

## 硬约束

- [ ] ⭐ 记忆索引已读（MEMORY.md 至少浏览一遍）
- [ ] ⭐ 不得兜底规则已确认
- [ ] ⭐ 不确定就问 / 删写前列清单已确认

## 文档系统

- [ ] 主索引（docs/index.md）时间戳为最近收工日期
- [ ] 任务索引（docs/tasks/index.md）包含最近全部任务条目
- [ ] 每项新任务均有 `Txxx-prompt.md` 提示词归档（无提示词下发的任务可豁免）
- [ ] 上轮对话文件 / 任务文件实际存在

## 代码健康

- [ ] Git 工作树干净（`git status`）
- [ ] 测试全部通过（`pytest ...`）
- [ ] HEAD 与交接文件记录一致

## 服务状态

- [ ] 各服务运行中 + 健康检查通过（端口 + HTTP 200）

## 数据质量

- [ ] 核心数据指标正常（记录数 > 0、缺失率在基线内、最新日期新鲜）

## 已知限制追踪

- [ ] 从上轮交接文件复制"已知问题"，逐项确认是否已处理

## 行动规则

| 检查结果 | 处理方式 |
|---------|---------|
| 全部 ✅ | 继续工作 |
| 有 ⚠️（已知基线） | 记录但可继续 |
| 有 ❌ | 先修再继续，不得跳过 |
